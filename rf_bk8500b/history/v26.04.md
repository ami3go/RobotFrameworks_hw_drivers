# v26.04 — RFDS AI Contract Integration

**Release date:** 2026-07-21  
**Archive:** `rf_bk8500b_v26.04.zip`  
**Python distribution:** `robotframework-bk8500b` 26.4.0

## Changes

- Added canonical `ai/ai_contract.yaml` conforming to the RFDS-017 v3 mandatory
  sections and covering all 74 public Robot Framework keywords exactly once.
- Added exact keyword signatures, state validity, resulting states, inputs, outputs,
  preconditions, postconditions, side effects, risk, timing, stabilization, retry,
  error references, exclusive resources, and planning priority.
- Added a closed error catalogue with post-error state and concrete recovery actions.
- Added machine-checkable safety limits, forbidden sequences, delays, safe teardown,
  verification objectives with pass/fail oracles, and multi-driver templates.
- Added `ai/ai_contract.lock`, computed from the public keyword names and signatures,
  so stale AI documentation is detected after interface changes.
- Added project-local `ai/rfds017.schema.json` and `scripts/verify_ai_contract.py`.
- Added RFDS-018 `bench/system_ai_contract.yaml` as an explicitly incomplete and
  conservative bench template; no actual laboratory wiring is claimed.
- Added AI-contract and bench-template documentation and traceability records.
- Added CI, test-script, build-script, structure, sdist, wheel, and release checks for
  the new contract files.
- Included the AI and bench contract resources in the wheel, source distribution, and
  complete release ZIP.

## Compatibility

No existing Robot keyword name, parameter order, default, or instrument-control
implementation changed. The public keyword surface remains 74 keywords.

## Qualification status

Software and fake-transport validation remain applicable. Real hardware, exact firmware
support, model-specific resistance and slew limits, and the actual test-bench topology
remain pending and are represented conservatively as `UNKNOWN`.
