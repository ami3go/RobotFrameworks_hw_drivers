# Robot Framework examples

All examples use the RFDS-002 v1.1 canonical keyword API and default to the
in-process `SIM::default` chamber. Replace the resource only after reading the
hardware setup and safety guides.

Run one example:

```powershell
python -m robot --outputdir results/examples/01 examples/01_basic_connection.robot
```

Run all examples with `scripts/run_all_examples.ps1` or `.sh`.
