# Release History

This folder is the release-by-release engineering history for the Robot Framework driver package.

Each release must add one Markdown file named `vYY.RR.md`, for example `v26.01.md`. The file records:

- user-visible changes;
- driver and keyword changes;
- safety-related changes;
- documentation changes;
- test and validation evidence;
- known limitations and migration notes.

Do not overwrite an older release history file. Add a new file for every update so the package remains auditable after the top-level project folder is replaced by a newer release.
