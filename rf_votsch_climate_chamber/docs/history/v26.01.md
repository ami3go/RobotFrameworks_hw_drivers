# Release History — v26.01

**Archive:** `rf_votsch_climate_chamber_v26.01.zip`  
**Fixed archive root:** `rf_votsch_climate_chamber/`  
**Python distribution version:** `26.1`

## Release purpose

Initial production-oriented Robot Framework package for a Vötsch/SimServ-compatible climate chamber. The package keeps the Python transport driver separate from the Robot Framework adapter so both layers remain independently testable and reusable.

## Driver changes

- Retained the industrial TCP driver and its legacy Python API.
- Added deferred connection support so Robot library import and Libdoc generation do not contact hardware.
- Added explicit connection verification and reconnect behavior.
- Added retained receive buffering so bytes after a protocol terminator are not lost.
- Added validation for timeout, response-size, retry, port, and backoff configuration.
- Preserved typed communication, protocol, command, timeout, and safety exceptions.
- Added cancellable and finite stabilization behavior for long-running tests.
- Kept temperature bounds strict; unsafe values fail instead of being clamped.

## Robot Framework adapter changes

- Added a suite-scoped adapter using composition and explicit `@keyword` exposure.
- Added 36 documented keywords for lifecycle, identity, status, temperature, stabilization, gradients, auxiliary outputs, diagnostics, and assertions.
- Added Robot Framework time-string conversion.
- Added safe teardown that always attempts both stop and disconnect.
- Added Robot-native logging without ANSI terminal sequences.
- Deliberately omitted arbitrary raw command execution from the public Robot API.

## Test and simulator changes

- Added Python unit tests and Robot Framework acceptance tests.
- Added a deterministic fake TCP chamber server for protocol and failure-path testing.
- Added an opt-in real-hardware smoke suite protected by `ALLOW_CHAMBER_CONTROL`.
- Added coverage, lint, type-checking, packaging, clean-install, and Libdoc validation.

## Documentation and examples

- Added architecture, safety, testing, troubleshooting, keyword, validation, and release documentation.
- Added 13 executable Robot Framework examples.
- Added Windows and Linux helper scripts.
- Added PyCharm and Robot Framework setup guides.
- Added MkDocs configuration and a GitHub Pages deployment workflow.

## Package-format update

The release now follows the Robot Framework Driver project convention:

```text
rf_votsch_climate_chamber_v26.01.zip
└── rf_votsch_climate_chamber/
```

Future archives use a new version in the ZIP filename but keep the same internal root folder so extraction replaces the existing project cleanly.

## Known limitations

- Production validation on the user’s actual chamber model is still required.
- Humidity and chamber-program/profile control are outside the v26.01 public keyword scope.
- Digital-output channel mappings must be confirmed against the specific chamber configuration before use.
