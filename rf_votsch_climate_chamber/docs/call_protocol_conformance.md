# RFDS-019 Call and Protocol Conformance

The package contains a complete keyword inventory, protocol vectors, exclusions
file, response schema, simulator suite, and Robot-side evidence harness. Static
coverage is validated for all exported keywords. Full runtime status is NOT_RUN
in this build because Robot Framework was unavailable; therefore the release is
not claimed as D1/P1. Execute `python scripts/run_conformance.py`
in an installed environment to generate timestamped Robot and protocol evidence.
