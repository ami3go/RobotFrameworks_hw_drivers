# v26.06 Code Review

## Trigger

A real Robot Framework execution of `driver_call_protocol_conformance.robot` failed because the inventory was evaluated alphabetically. `Cancel Current Operation` and multiple assertion/query keywords ran before `Connect`; later disconnect keywords also removed the shared session, causing cascading `RFDS-CON-002` failures.

## Root cause

The previous harness treated keyword inventory enumeration as an executable sequence. RFDS-019 requires explicit preflight, communication establishment, valid keyword preconditions, protocol verification, recovery, and trace evidence. Alphabetical inventory order is metadata order, not a valid state-machine test plan.

## Corrections

1. Added deterministic per-keyword precondition setup.
2. Added session isolation and recovery around lifecycle-changing keywords.
3. Added simulator state preparation for assertions and control operations.
4. Added configuration-profile fixtures and cleanup.
5. Added real protocol trace capture and ordered vector comparison.
6. Added direct regression coverage for all 92 public keywords.
7. Added approved simulator support to the deprecated connection adapter.
8. Corrected disconnect and safe-shutdown protocol vectors.
