# Governance

The package follows the RFDS source documents supplied with the project. RFDS-002
owns canonical Robot API semantics; RFDS-005 owns the flat package layout;
RFDS-017 owns the AI driver contract; RFDS-019 owns call/protocol conformance.
Conflicts are recorded in `api/decisions.yaml` and are never silently resolved.
P1 claims require complete simulator, Robot-runtime, and representative real-device
evidence with no mandatory item marked NOT_RUN.
