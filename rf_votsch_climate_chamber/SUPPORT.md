# Support

When reporting an issue, include:

- release, Python, and Robot Framework versions;
- operating system;
- chamber model and firmware when known;
- redacted connection parameters;
- Robot `output.xml`, `log.html`, and relevant traces;
- `Get Diagnostics` output;
- exact keyword arguments and error code.

Do not include facility credentials, proprietary DUT data, or unredacted network
information.
